# 2026-10-28

## 修 bug：编辑器滚动时位置突然跳变

**现象**：长文件里轻轻滚一下，视图从 54-99 行直接跳到 93-129 行。

**排查过程**（用独立控制台程序加载 CodeEditor 实测，验证后已删测试文件）：
1. 打印滚动条参数 → 发现 `QPlainTextEdit` 垂直滚动条单位是**行**不是像素，
   `max = blockCount - pageStep`，`singleStep = 1`，一格滚轮 = 3 行
2. 连续滚 60 格（NoWrap / 折行 / 折叠后三种场景）→ 每格稳定 +3，**异常 0 次**，滚动本身没问题
3. 突破口：用户描述「46 行 → 37 行」，同一窗口一屏行数不可能变 → 说明有 9 行被折叠隐藏了
   → 锁定折叠系统

**两个叠加的根因**：
1. **`QSyntaxHighlighter` 和 `FoldManager` 抢 `QTextBlock::userState` 同一个字段**
   - `setCurrentBlockState()` 写的就�� userState
   - CodeHighlighter 用 `InBlockComment = 1`，FoldManager 用 `userState & 1` 判断「已折叠」
   - → 块注释内的行被误判成折叠起点 → 整块代码被静默隐藏
   - 反向污染：`setUserState(1)` 还会把高亮器的块注释状态抹成 0，折叠后注释染色失效
2. **`scanRegions()` 不识别块注释**，注释里的 `{ }` 被当成真括号 →
   制造假折叠区，且消耗掉真实括号配对 → 后续所有折叠区整体错位

**修复**：
- `foldmanager.cpp`：折叠状态改存 `QTextBlockUserData`（`FoldData` 类），彻底与高亮器隔离；
  选 userData 而不是 `QSet<int>` 是因为它跟着 block 走，undo/redo / 插入删除行时自动跟随
- `scanRegions()` 加跨行块注释状态机（状态声明在循环外，因为注释可跨几十行）
- `codeeditor.cpp` 的 `onTextChanged()`：rescan 前后比较隐藏行数，变了就 `scrollToBlock(topNumber)` 拉回
- `scrollToBlock()` 关键：**不能把 blockNumber 当 scrollbar value 用**，
  要数一遍目标行前面有多少可见行（实测印证：折叠后 setValue(50) 实际对应第 60 行）
- 顺手修死代码：`revealCursor()` 定义了从未被调用（注释却说会被调），补进 `onCursorPositionChanged()`

**验证**：注释里的 `{` 折叠 0 行、`void foo{}` 折叠 6 行、`if{}` 折叠 1 行、行注释 `{` 折叠 0 行；
高亮器 userState 保留正常；编译 0 error 0 warning。

**文档**：`docs/Bug排查-滚动位置突变.md`（含完整排查实验数据 + 5 条可复用的 Qt 知识点）

## 修 bug 二：全部折叠后滚动出现内容重复

**现象**：`foldAll()` 之后向上滚，`}` 被重复画 5 遍；滚过头则一片空白。

**根因**：`QTextBlock::setVisible(false)` **不会**通知 `QPlainTextDocumentLayout` 重新排版。
该 layout 维护一张 `blockNumber -> y` 的表，滚动条 range、`firstVisibleBlock()`、
`contentOffset()` 全依赖它。隐藏 466 行后表里仍按旧量级算：
- 实测 `docH` 605 → 428（正确应为 139），`max` 573 → 395（正确 106）
- 绘制位置与位图滚动量对不上 → 旧像素没被覆盖 → 内容重复 / 空白

**修复**：
- `FoldManager::applyVisibility()`：只对真正变化的 block 调 `setVisible`，记下第一个变化的
  `position()`，然后 `_doc->markContentsDirty(firstChanged, characterCount - firstChanged)`
  强制 layout 重排。加 `_applying` 防重入（markContentsDirty 可能同步引发 textChanged → rescan）。
- `CodeEditor::changeFold(std::function<void()>)`：四个折叠入口统一走它，
  变更前记 `firstVisibleBlock().blockNumber()`，变更后 `scrollToBlock()` 拉回。
  **必须记 blockNumber 不能记 scrollbar value**（value 数的是可见行，折叠前后会变）。

**验证**：618 行文件 foldAll → docH 155 = 618-463 ✓；往返折叠/展开高度复原；
逐格 setValue 扫描整条滚动条顶部 block 零回退；真实滚轮上滚每次稳定 -3 行；
`QScreen::grabWindow(0)` 抓真实屏幕（不触发重绘，能看见位图残留）确认无重复无空白。
编译 0 error 0 warning。

**经验**：
- 在 `QPlainTextEdit` 上做折叠，`setVisible(false)` 后必须 `markContentsDirty()` ——
  网上大量示例都漏了这一步，小文件不滚动看不出，一滚就露馅。
- `QTextDocument::size().height()` 是排查布局问题的第一现场：应始终等于「可见行数」。
- 保持视图位置要记模型坐标（blockNumber），不要记视图坐标（scrollbar value）。
- 消息：PowerShell 的 `Add-Type` 被安全策略拦截，抓屏改用 Qt 的 `QScreen::grabWindow(0)`。
