## 为 CodeEditor（Qt6 Widgets 项目）新增左侧资源管理器 + 顶部标签页栏 + 打开文件夹

**原则**：不改动 CodeEditor / CodeHighlighter / FoldManager / BracketMatcher / LineNumberArea 任何一行，
全部通过新建文件 + 外壳重写实现。

**新增文件**
- `fileexplorer.h/.cpp`：QFileSystemModel + QTreeView 的侧栏。坑点：模型异步加载，必须在
  `directoryLoaded` 信号里再 expand 根节点；过滤用 `setNameFilters` 而非 QSortFilterProxyModel（后者会毁掉懒加载）。
- `editortabs.h/.cpp`：QTabWidget，每个 tab 一个 CodeEditor。元数据用 `setProperty("filePath"/"savedText")`，
  脏标记靠「文本 != savedText」比对，不给原类加成员；打开内容用 `beginEditBlock` 合并成一次文档操作；
  0 号 tab 是 BlankPage 欢迎页（不可关闭），保证 currentWidget 永远非空。

**修改文件**
- `mainwindow.h/.cpp`：QSplitter(FileExplorer | EditorTabs)；`_editor` 语义改为「当前标签页编辑器」（可为空）；
  新增 `attachEditor()` 负责切标签时 disconnect 旧 + connect 新；折叠/换行 connect 改 lambda 取当前编辑器；
  新增 openFolder / onFileActivated / toggleExplorer / resetEditorState；关闭确认从析构函数迁到 `closeEvent()`。
- `main.cpp`：命令行参数统一走 `window.openPath()`。
- `CMakeLists.txt`：新文件收进 `EXTRA_SOURCES` 变量（方便回退）。
- `theme.cpp`：QSS 末尾追加侧栏/标签栏/空白页样式，旧规则未动。

## 追加修复：标签关不掉

**现象**：用户反馈标签没有关闭按钮 / 点了关不掉。

**根因**：`theme.cpp` 里 `QTabWidget#editorTabs QTabBar::close-button { image:none; ... }`
把 Qt 自带 close-button 的图形抹掉了，Fusion 描边色 ≈#2c2c36 与标签底色 #1a1a21 几乎同色
→ 一个「看得见位置、看不见图标、还能点」的空洞。（经临时程序渲染按钮像素验证，验证后已删除测试文件）

**修复**：
1. 自绘 `CloseButton`（QToolButton 子类，重写 paintEvent 画两根 45° 线），完全绕开 QSS 伪元素；
   `setFocusPolicy(Qt::NoFocus)` 防抢焦点；点击时 `emit bar->tabCloseRequested(idx)`。
2. 新增 `renumberCloseButtons()`：任何增删/移动标签后整体重挂按钮（下标会变）。
3. 修 `maybeClose` 里 `removeTab` 之后还读 `tabText(index)` 的悬空下标问题（取值全部提前）。
4. 补齐 5 条关闭入口：标签 ×、右键菜单（关闭/关闭其他/关闭右侧/关闭所有）、
   工具栏「关闭标签」「全部关闭」、`Ctrl+W` / `Ctrl+F4` / `Ctrl+Shift+W`。
5. `MainWindow::buildShortcuts()`：快捷键挂 QMainWindow + `Qt::WindowShortcut`，
   焦点在编辑器内也能触发且不与 QPlainTextEdit 抢键。
6. 批量关闭必须**倒序**遍历，否则删元素导致下标前移跳过项。

**经验**：QSS 里写 `image:none` 到 `::close-button` / `::branch` / `::indicator` 这类伪元素，
等于把该控件的图标彻底抹掉。要么给 image 指定资源，要么像这次一样自绘。
